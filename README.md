# FrameGen WebGPU

Браузерное расширение (Chromium Manifest V3) для генерации промежуточных кадров (60–240 FPS) и масштабирования видео в 1440p / 4K в реальном времени через **WebGPU**.

---

## Возможности

### 1. Генерация кадров
* **Фиксированный множитель:** `x2`, `x3`, `x4`.
* **Целевой FPS (Target FPS):** точная подгонка частоты под частоту развёртки монитора (60, 75, 90, 120, 144, 165, 240 FPS) без плавающего фреймрейта.
* **Авто-пропуск:** автоматическое отключение генерации для видео, исходный FPS которых выше заданного порога (например, 60 FPS).
* **Каденс аниме:** обнаружение дублированных кадров рисованной анимации (2s/3s) для устранения дрожания.

### 2. Алгоритмы масштабирования

| Алгоритм | Тип | Назначение |
| :--- | :--- | :--- |
| **SPAN x2** | Нейросеть (WebGPU) | Субпиксельное внимание (Attention), максимальная резкость линий без артефактов |
| **Real-ESRGAN Compact** | Нейросеть (WebGPU) | Подавление артефактов сжатия, блочности и звона |
| **AMD FSR 1.0** | Шейдер (EASU + RCAS) | Направленная интерполяция Ланцоша и адаптивный шарпенинг для кино и сериалов |
| **Anime4K v4.0** | Шейдер | Морфологическое утончение линий и восстановление контуров |
| **Bicubic Catmull-Rom** | Шейдер | Натуральное сплайновое масштабирование |
| **Выкл (1:1)** | Прямой вывод | Без масштабирования (только интерполяция кадров) |

### 3. Целевые разрешения
* **1440p (2560×1440)** — для 2K мониторов.
* **4K UHD (3840×2160)** — для 4K экранов и ТВ.
* **Авто** — подгонка под текущее окно плеера / экрана.

### 4. Интерфейс и управление
* **Быстрый тумблер слева:** компактная кнопка `ON / OFF` по центру плеера.
* **Мониторинг (Shift + D):** оверлей с текущим FPS, задержкой рендера в миллисекундах, разрешением и активным движком.
* **Локализация:** переключение между русским и английским языками (RU / EN).
* **Проверка обновлений:** проверка новых версий напрямую с GitHub Releases.

## Установка

1. Скачайте архив **`FrameGen-VideoUpscaler.zip`** из вкладки [Releases](../../releases/latest).
2. Распакуйте архив в удобную папку.
3. Откройте в браузере страницу:
   ```text
   chrome://extensions/
   ```
4. Включите **«Режим разработчика»** в правом верхнем углу.
5. Нажмите **«Загрузить распакованное расширение»** и выберите папку с распакованными файлами.

## Горячие клавиши

| Клавиша / Действие | Функция |
| :--- | :--- |
| **Shift + D** | Показать / скрыть панель мониторинга (FPS, задержка, поток) |
| **Наведение на левый край** | Показать быстрый переключатель `ON / OFF` |

## Сборка из исходников

Требуется **Node.js 18+** и **npm 9+**.

```bash
git clone https://github.com/demonqwe/framegen-webgpu.git
cd framegen-webgpu

npm install
npm run build      # сборка в dist/
npm run pack       # сборка и упаковка FrameGen-VideoUpscaler.zip
```
