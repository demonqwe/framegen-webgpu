# FrameGen WebGPU

Браузерное расширение (Chromium Manifest V3) для генерации промежуточных кадров (60–240 FPS) и масштабирования видео в 1440p / 4K в реальном времени через прямой **WebGPU Compute**.

---

## Ключевые возможности

### 1. Нейросетевая интерполяция кадров (EMA-VFI WebGPU)
* **Прямой WGSL Compute рантайм:** нейросеть выполняется непосредственно на видеокарте через WebGPU шейдеры без тяжелых библиотек (ONNX Runtime, PyTorch, WASM).
* **Zero-Copy Pipeline:** сгенерированный промежуточный кадр передаётся в апскейлер напрямую в видеопамяти без задержек и копирования в оперативную память.
* **Выбор моделей нейросети:**
  * **`v7 Small (2.9 МБ)`** — сверхбыстрая модель с минимальной задержкой.
  * **`v6 T-Fact2 (4.5 МБ)`** — модель с улучшенной компенсацией окклюзий и сложных движений.
* **Качество расчёта (Разрешение входа):**
  * `Нативное (Full)` — максимальное качество деталей (рекомендуется для мощных GPU уровня RTX 4070 / 5060 Ti и выше).
  * `720p (Сбалансированное)` — облегченный расчет с последующим апскейлом до 4K через FSR 1.0 (для средних видеокарт).
  * `540p (Слабый ПК / Ноутбук)` — ультралегкий режим для встроенной графики (Intel Iris Xe, AMD Radeon 680M/780M).
* **Резервный движок:** аппаратный шейдерный поток движения (`Motion Flow`), вычисляющий векторы по блокам пикселей.

### 2. Умный каденс аниме (Anime Cadence)
* Традиционное японское аниме рисуется с частотой 8–12 FPS (на «двойках» или «тройках»), в то время как видеофайл воспроизводится в 24 FPS с дублирующимися кадрами (`A-A-B-B`).
* Встроенный шейдерный анализатор разницы кадров отслеживает дубликаты и автоматически пропускает их, предотвращая артефакты «студня» и микро-фризы.

### 3. Быстрые пресеты в 1 клик
* 🌸 **Аниме:** модель `v6 T-Fact2` + апскейлер `Anime4K v4.0` + Каденс `ВКЛ` + Нативное качество.
* 🎬 **Кино:** модель `v7 Small` + апскейлер `AMD FSR 1.0` + Каденс `ВЫКЛ` + Нативное качество.
* ⚡ **Эко / 720p:** модель `v7 Small` + разрешение `720p` + апскейлер `AMD FSR 1.0`.

### 4. Независимые профили сайтов (Per-Site Profiles)
* Настройки (Вкл/Выкл, пресет, модель, апскейлер) сохраняются **индивидуально для каждого домена** (`youtube.com`, `jut.su`, `twitch.tv`, `kinopoisk.ru`).
* В шапке расширения отображается активный сайт, а кнопка **«💾 По умолчанию»** позволяет сделать текущие настройки шаблоном для всех новых сайтов.

### 5. Энергосбережение (GPU Saver)
* При сворачивании окна, переключении на соседнюю вкладку или прокрутке страницы за пределы плеера конвейер генерации мгновенно засыпает (**0% нагрузки на GPU**).

## Горячие клавиши

| Клавиша | Функция |
| :--- | :--- |
| **G** | Быстрое включение / выключение генерации кадров для текущего сайта |
| **C** | Моментальное сравнение «До / После» (A/B тест между исходным видео и 60 FPS) |
| **Shift + D** | Показать / скрыть панель мониторинга WebGPU (FPS, активная модель, статус каденса) |

## Алгоритмы масштабирования

| Алгоритм | Тип | Назначение |
| :--- | :--- | :--- |
| **AMD FSR 1.0** | WebGPU Шейдер (EASU + RCAS) | Адаптивная резкость и интерполяция Ланцоша для фильмов и сериалов |
| **Anime4K v4.0** | WebGPU Шейдер | Восстановление четкости контуров и линий для аниме и мультфильмов |
| **Bicubic Catmull-Rom** | WebGPU Шейдер | Мягкое натуральное 16-точечное сплайновое масштабирование |
| **Выкл (1:1 Direct)** | Прямой вывод | Без масштабирования (только интерполяция кадров) |

## Установка в браузер

1. Скачайте архив **`FrameGen-VideoUpscaler.zip`** из вкладки [Releases](../../releases/latest).
2. Распакуйте архив в любую постоянную папку на компьютере.
3. Откройте в браузере:
   ```text
   chrome://extensions/
   ```
4. Включите **«Режим разработчика»** (в правом верхнем углу).
5. Нажмите **«Загрузить распакованное расширение»** и укажите распакованную папку.

---

## Сборка из исходников

Требуется **Node.js 18+** и **npm 9+**.

```bash
git clone https://github.com/demonqwe/framegen-webgpu.git
cd framegen-webgpu

npm install
npm run build      # сборка в папку dist/
npm run pack       # сборка и упаковка FrameGen-VideoUpscaler.zip
```
