Высокопроизводительное браузерное расширение для генерации **60 FPS** и аппаратного апскейла (**Anime4K v4.0 / AMD FSR / Bicubic**) на видеокартах **NVIDIA GeForce RTX, AMD Radeon, Intel ARC и встроенной графике (iGPU)** через чистый **WebGPU**.

---

## 🌟 Главные возможности

* 🚀 **Ультра-плавные 60 FPS на любом видео:**
  Преобразует 24 fps видеопотоки (кино, сериалы, аниме, стримы) в 60 кадров/сек в реальном времени с нулевой задержкой и без смазывания контуров на сменах сцен.

* 🎨 **4 режима аппаратного масштабирования (WGSL Shaders):**
  * **Anime4K v4.0 (Line Thinning + Catmull-Rom + CAS):** идеальная резкость и утончение контуров для рисованного контента без зазубрин на субтитрах и тексте.
  * **AMD FSR (EASU + RCAS):** 12-точечная направленная интерполяция Ланцоша с контрастно-адаптивным повышением резкости для фильмов и реалистичных видео.
  * **Bicubic Catmull-Rom (16-Tap):** естественное сглаживание сплайнами без изменения геометрии рисунка.
  * **Bypass (1:1):** отключение апскейла с сохранением 60 FPS интерполяции.

* 🎬 **Поддержка NVIDIA RTX Video Super Resolution (VSR):**
  Сквозной режим нативного воспроизведения позволяет аппаратному драйверу NVIDIA RTX апскейлить оригинальный `<video>` поток.

* 🧠 **Интеллектуальная память настроек для каждого сайта:**
  Расширение автоматически запоминает выбранный режим для каждого домена (например, нативный VSR на *YouTube* и 60 FPS на видеосайтах).

* 🎛️ **Ультра-минималистичный боковой микро-тумблер:**
  Полностью скрыт во время просмотра. Плавно выезжает только при подведении курсора к левому краю видеоплеера, позволяя переключать режимы в один клик.

* 📊 **Мониторинг видеопотока (Shift + D):**
  Компактный OSD-интерфейс в стиле RivaTuner с отображением трансформации частоты кадров (`24 FPS → 60 FPS`), разрешения и параметров шейдера.

* 🌐 **Универсальная совместимость:**
  YouTube, YouTube Shorts, Kodik, AnimeGo, Jut.su, YummyAnime, Shikimori, VK Видео, Кинопоиск, плееры Aloha и любые HTML5 видео.

## 📦 Быстрая установка (для пользователей)

1. Скачайте архив **`FrameGen-VideoUpscaler.zip`** из вкладки [**Releases**](../../releases/latest).
2. Распакуйте архив в любую постоянную папку (например, `C:\FrameGen`).
3. В браузере (*Chrome, Яндекс Браузер, Edge, Brave, Opera*) перейдите по адресу:
   ```text
   chrome://extensions/
   ```
4. В правом верхнем углу включите тумблер **«Режим разработчика»** (*Developer mode*).
5. В левом верхнем углу нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите распакованную папку.
6. Готово! Расширение активировано и работает на всех поддерживаемых видеосайтах.

## ⌨️ Управление и горячие клавиши

| Действие | Как выполнить |
| :--- | :--- |
| **Быстрое переключение (60 FPS ↔ VSR)** | Подвести курсор к левому краю плеера по центру |
| **Панель мониторинга (OSD)** | Нажать `Shift + D` во время видео |
| **Выбор алгоритма апскейла** | Значок расширения на панели браузера (Anime4K / FSR / Bicubic) |
| **Скрыть боковой тумблер** | Снять галочку в меню расширения |

## 🛠️ Сборка из исходников (для разработчиков)

### Требования
* **Node.js** >= 18
* **npm** >= 9

```bash
# Клонирование репозитория
git clone https://github.com/demonqwe/framegen-webgpu.git
cd framegen-webgpu

# Установка зависимостей
npm install

# Проверка типов TypeScript
npm run type-check

# Сборка расширения (папка dist/)
npm run build

# Сборка и упаковка готового zip-архива
npm run pack
```
